v0.10.0 默认推荐以上六个对应 App：录音机、设置、智能助理、安装器、系统桌面、搜索，仍可按需勾选；推荐列表不强制改变已有用户的勾选。智能助理、安装器、系统桌面及搜索被排除在通用 CN 伪装之外，使用已核验 APK 的独立窄适配；无机型白名单，但其他 APK 版本会因安全检查不匹配而不处理。

其他由用户额外勾选、通过系统应用及系统分区路径检查的 App，默认沿用录音机的进程内 CN 兼容：区域属性与 MIUI 国内版判断在该进程中提供国内结果，实际系统全局区域不变。未勾选的 App 不处理；普通第三方数据应用仍不处理。设置、智能助理、安装器、系统桌面和搜索优先使用各自专门策略，专门适配不匹配时保留原行为；小米服务框架始终排除，避免与超级岛重复处理。

“CN 兼容”包含版本判定，并非只覆写地区字符串：2026-10-31 核对 EU307 原始属性时，地区已为 CN，而 `ro.product.mod_device=dada_xiaomieu_global`。该录音机直接依据 `_global` 判断国际版，并据此关闭应用录音入口。进程内移除 Xiaomi.eu/global 后缀及修正国际版判断，才是此场景中关键的差异；XMSF 自己的 China/CN 推送缓存不能代替这项版本判断。

负一屏不改隐私授权、行程提醒/自动添加选择、服务器、代理、卡片或账号数据。小部件网络问题已通过用户现有 VPN 分流解决，不打包网络拦截器或响应内容日志。真实行程上岛仍需用户的真实行程验证。

系统应用更新适配仅覆盖已核验安装器中的普通 APK 文件解析路径，不承诺绕过所有安装渠道/会话限制；签名、版本降级、权限等系统检查保持原样。迁移须先验证局部标记在全局属性关闭时生效，才停用旧 system allow 模块。
