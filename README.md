# EuLocation（测试版）【hyper eu本地化模块】

已验证 **小米 15（dada）/ xiaomi.eu HyperOS 3 OS3.0.307.0.WOCCNXM** 的 KernelSU 可选本地化模块，包含超级小爱和小米钱包。不是定位/GPS 模块，不一定适用于所有 EU ROM 的通用包。

> 当前为预发布测试版。仅在下述机型、ROM 和现有环境中测试；安装前请自行备份，并准备好可用的模块停用/救援方式。支付相关功能未做真实交易验证。

## 小爱与钱包可以分别选择安装

这是一个二合一安装包，但**不是强制同时安装，也不是只能二选一**：

| 组件 | 包含内容 | 是否可独立安装 |
| --- | --- | --- |
| 超级小爱 | 小爱核心 + 语音唤醒 | 可以，核心与唤醒作为一个选项 |
| 小米钱包 | 钱包及其五组件服务栈 | 可以 |

支持「只装小爱」「只装钱包」「小爱和钱包都装」。安装时依次询问两个选项：

- **音量上键**：安装/更新该组件。
- **音量下键**：跳过该组件。
- 每项等待 30 秒，超时取消安装，不会静默默认全选；两项都跳过也会取消。

跳过不会删除独立安装的旧模块或应用数据。**更新本模块时，不支持通过取消选择来移除已经由本模块管理的组件**，这种情况会中止安装。不要把安装选择菜单当成组件卸载菜单。

本次是在已有 Root/LSPosed 配置的设备上迁移并测试，不是干净 ROM 的独立对照实验；不宣称所有环境均不需要其他现有配置。

## 下载与安装

1. 在 [Releases](https://github.com/tiancaiProgramer/EuLocation/releases) 下载测试版 ZIP 和 `SHA256SUMS.txt`，核对 SHA-256。
2. 在 KernelSU 管理器中从本地安装 ZIP，按音量键分别选择小爱、钱包。请保持屏幕可查看安装日志。
3. 安装成功后，如果存在覆盖同一 APK 的旧小爱/钱包模块，只停用本次所选组件对应的旧模块；不要让新旧重复载荷同时启用。保留自己的兼容备份以便回退。
4. 检查 KernelSU 应用配置：所选组件相关进程必须能看到模块挂载，即相关应用的「卸载模块 / Umount modules」应关闭。不要因此授予应用 Root，也不要全局取消模块隐藏。
5. 重启并解锁，手动检查小爱/钱包。首次安装需要本人确认权限、选择默认助手及录入唤醒词；不要为迁移无故重新录入或清除应用数据。

需要检查挂载可见性的进程包括 `android`、`com.android.nfc`（NFC 共享 UID 相关配置），以及所选组件的包名：

- 小爱：`com.miui.voiceassist`、`com.miui.voicetrigger`。
- 钱包：`com.miui.tsmclient`、`com.mipay.wallet`、`com.miui.nextpay`、`com.unionpay.tsmservice.mi`、`com.xiaomi.payment`。

若安装器提示已安装 APK 路径或哈希不同（例如存在 `/data/app` 更新），请停止并排查版本，不要通过清数据、强制降级或删除卡片解决。安装器不自动更改默认助手、默认支付应用或权限配置。

高级部署另有一次性、root 所有且权限为 0600 的 ADB 选择文件入口。发布包不附带预选文件，正常手动安装仍显示两个菜单。

## 已验证与未验证

已验证：

- 小爱可以打开，默认助手绑定正常；沿用原录入，在桌面和锁屏状态均能语音唤醒，重启后仍正常，无需重新录入。
- 钱包首页与原有卡片显示正常，NFC 开启状态及原默认设置保留。
- 所选组件载荷校验通过；迁移过程未清除应用数据、录入、卡片或原有设置。
- 选择逻辑 12/12 测试通过（包括模拟音量键和超时）；Android 上两组件独立解包测试 2/2 通过。实际迁移采用明确的 ADB 双选，未把实体按键手动操作当作已完成的实机测试。

**未验证**：真实支付、开卡/删卡、交通卡/门禁卡完整操作、银行认证、全部云端小爱能力、长期耗电、DSP 低功耗保证、OTA 升级及其他机型/ROM。首页可打开不代表所有金融业务均可用。

## 载荷来源与边界

- 小爱：沿用原签名核心和唤醒载荷；VoiceAssistAndroidT 7.12.2.0318、VoiceTrigger v-8.0.0.30-xiaomi。
- 钱包：TSMClient 26.04.27.1.f、MipayWallet 6.111.0.5701.2736、MINextpay 26.01.30.1、UPTsmService 01.00.57、PaymentService 2.9.8。
- 钱包 EU307 适配是安装器/运行环境兼容适配：沿用 CN dada305 组件及此前核验过的小米签名钱包版本，**不是声称载荷提取自 CN307**。小爱同样沿用此前已测载荷，不是完整移植整个国行 AI 系统。
- 仅选择钱包时携带原有 `ro.se.type=eSE,HCE,UICC` 和 `moe.minamigo.hyperos3wallet=v1.0` 属性。不做全局 CN 区域伪装，不放宽签名或 SELinux。
- 不替换 AIService、AICR、视觉、语音引擎、vendor 或 DSP；依赖系统现有语音引擎和 NFC/eSE/HCE 能力。
- 不打包、导出或复制用户的语音录入、卡片/账号数据库、支付密钥或个人备份。

## 回退与 OTA

遇到问题先停用本模块并重启；如有自行保留的兼容旧模块，可以在停用新模块后恢复对应旧模块，不能重复覆盖。卸载脚本不会清除应用数据，也不会自动恢复默认助手或重新启用旧模块。彻底移除助手/钱包提供者前，请自行选择合适的替代默认应用。OTA 前先停用测试模块；升级后不要绕过版本检查继续使用。
