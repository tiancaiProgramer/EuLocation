# 实时服务超级岛适配 v0.18

测试基线：小米15（dada）／xiaomi.eu OS3.0.307.0.WOCCNXM／Android 16。其它系统版本、机型和完整滴滴行程尚未在本版验证。APK 使用 libxposed API 102，不是 KSU ZIP。

## 用途与作用域

在 LSPosed 启用，按已安装应用勾选：

- 淘宝闪购／饿了么 `me.ele`
- 滴滴 `com.sdu.didi.psnger`
- 系统界面 `com.android.systemui`
- 系统界面组件 `miui.systemui.plugin`
- 小米服务框架 `com.xiaomi.xmsf`

XMSF 交由本模块处理，EU增强不处理它。不要叠加其它同类区域或焦点通知改写。

## 版本变化

v0.15 在淘宝闪购主进程的前台恢复中，按已核验路由启动应用自身原生推送服务。每个进程成功请求一次；失败仅在后续前台回调、间隔至少30秒时重试。没有定时轮询、保活或模拟订单。真实订单显示及送达状态更新曾通过，冷启动后无需打开 App 的后台及时更新未证明。

v0.16 修正待付款状态筛选，保留已支付、取消、发票、聊天和推广排除；增加限量且不含正文、订单号及位置的诊断元数据。

v0.18 针对 EU307 的 XMSF **6.2.67-G / code60002067**：当包名、精确版本、MIUI 和 China 条件全部匹配，修复原版 China 启用判断、国内聊天主机及原生设备登记 URL。其它版本和地区不改写。不更改系统区域、属性、账号或登记缓存，也不 Hook system_server。

此前只恢复启用检查的 v0.17 仍走 Global 主机，登记报错；它是中间诊断版，不建议安装。

## 已验证与边界

实机已确认国内通道连接和绑定成功，滴滴 SDK regId 及业务 pushId 从空恢复有效；恢复平时代理后，新的连接和绑定仍成功。

**这是推送登记前置修复，不等于滴滴端到端上岛已完成。** 修复后仍需下一笔自然发生的真实行程验证活动创建参数、服务端活动数据和可见岛。无需为测试专门下单。手环通知流转尚未验证通过。
